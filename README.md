# MBTI 人格测试网站

免费在线 MBTI 十六型人格测评,纯静态站点,无需构建、无依赖、无后端。

## 功能

- **40 道情境题**:四个维度(E/I、S/N、T/F、J/P)各 10 题,五级李克特计分,题目顺序随机
- **16 型人格报告**:性格画像、潜在优势、注意盲区、适合领域、同款人格、默契搭档
- **维度倾向图**:各维度百分比条形图,展示倾向强度
- **分享卡片**:Canvas 生成 750×1000 分享图,可下载保存
- **进度保存**:localStorage 自动保存作答进度,中途退出可继续
- **响应式设计**:桌面 / 平板 / 手机全适配,支持键盘 1–5 快捷作答

## 目录结构

```
├── index.html        # 单页应用(落地页 / 答题页 / 结果页)
├── css/style.css     # 全部样式
└── js/
    ├── questions.js  # 40 道题库 + 维度定义
    ├── types.js      # 16 型人格数据
    └── app.js        # 状态机、计分、渲染、分享卡片
```

## 本地运行

任意静态服务器均可,例如:

```bash
python -m http.server 8080
```

然后访问 http://localhost:8080

## 部署

整个目录是纯静态文件,可直接上传到任意静态托管(GitHub Pages / Netlify / Vercel / Cloudflare Pages 等),无需构建步骤。
